# EstudoIA

## Diário Inteligente de Estudos

O EstudoIA é um aplicativo Android desenvolvido para ajudar estudantes a organizar os seus estudos.

### Funcionalidades principais

- Diário de estudos
- Organização de matérias
- Criação de resumos
- Gestão de tarefas
- Calendário de estudos
- Acompanhamento do progresso
- Assistente inteligente de estudos

### Objetivo

Tornar o estudo mais organizado, simples e produtivo.

Versão inicial: 1.0
